# War-Game

**War Game** is a digital implementation of the classic **Egyptian Ratscrew / War** card game, built with **React (Vite)**, **JavaScript**, and my custom CSS library.

The game features both **manual** and **automatic** play modes, with each match continuing until one player has collected all the cards or the opponent can no longer continue.

## Gameplay

The game is designed to be simple and fast:

- Each turn, both players draw a card from their pile.
- The player with the higher-value card wins the round.
- On draw both players pull additional 4 cards, and check the hands, the bigger hand wins.
- The player with winning hand takes all the cards and adds them to their pile.
- The game ends when one player owns all the cards or the other player has no valid moves remaining.

## Features

- Manual play mode
- Automatic play mode
- Built with React (Vite) and JavaScript
- Uses my custom CSS library for styling
- Lightweight, one-click gameplay

## Running Locally

1. Install the project dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open the local URL provided by Vite in your browser.
